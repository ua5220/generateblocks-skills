# Post Grid Prompt

## The Prompt

> Create a blog post grid layout with a featured large post on the left (taking up 2 rows) and 2 smaller posts stacked on the right. Each post shows: featured image, date, title, and excerpt. The featured post should be larger and more prominent. Add hover effects on all posts. Mobile: stack all posts vertically.

## Design Notes

- Asymmetric grid: 1 large (2x2) + 2 small (1x1)
- Featured post: full-height image with gradient overlay
- Small posts: horizontal card layout
- Date formatted nicely
- Mobile: single column stack
