# Logo Carousel Prompt

## The Prompt

> Create a client logo showcase section with "Trusted by industry leaders" heading. Display 6 company logos in a continuous scrolling marquee animation. Logos should be grayscale by default and colorize on hover. Include a subtle gradient fade on the edges. Mobile responsive.

## Design Notes

- Section padding: 4rem top/bottom
- Background: Light gray (#f5f5f3)
- Logos: Grayscale filter, full color on hover
- Animation: Smooth infinite scroll (CSS keyframes)
- Edge fades: Linear gradient masks on left/right
- Mobile: Same animation, smaller logos
