# FAQ Section Prompt

## The Prompt

> Create an FAQ section with 5 questions and answers. Style it as a clean list (not accordion) with question in bold and answer below. Add subtle visual separation between items. Include a section heading. Questions should have a decorative number or icon. Two-column layout on desktop (3 left, 2 right), single column on mobile.

## Design Notes

- Two-column masonry-style layout
- Numbered questions with accent color
- Clean typography hierarchy
- Subtle border or background separation
- Section header centered
- Mobile: single column stack
