# Feature List Prompt

## The Prompt

> Create a features section with 6 features in a 3x2 grid. Each feature has an icon (use inline SVG), title, and description. Add a subtle hover effect that highlights the feature. Include a section heading and subheading. Mobile: 2 columns on tablet, 1 on mobile.

## Design Notes

- 3x2 grid layout
- Icon in colored circle
- Icon rotates/scales slightly on hover
- Clean typography hierarchy
- Light background for contrast
- Centered section header
