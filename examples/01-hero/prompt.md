# Hero Section Prompt

## The Prompt

> Create a hero section with a headline, subheadline, two CTA buttons (primary and secondary), and a stats bar showing 4 metrics. Use a clean, modern design with hover effects on buttons. Mobile responsive.

## Design Notes

- Section padding: 4rem top/bottom
- Container max-width: 1200px
- Headline: Large, bold, clamp() sizing
- Stats: 4-column grid with dividers
- Buttons: Pill-shaped with hover lift effect
- Mobile: Stack stats 2x2, center text
