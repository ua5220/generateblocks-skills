# Hero Section

A clean hero section with headline, description, dual CTAs, and a 4-metric stats bar.

## Features

- Responsive headline with `clamp()` sizing
- Primary (filled) and secondary (outline) CTA buttons
- 4-column stats grid with gradient dividers
- Mobile: 2x2 stats grid, centered text
- Hover effects on all interactive elements

## Usage

1. Copy `output.html`
2. Paste into WordPress block editor (Code Editor mode)
3. Replace placeholder content
4. Switch to Visual Editor

## Customization

- Change colors: Replace `#c0392b` (primary) and `#0a0a0a` (text)
- Adjust stats: Modify the 4 stat blocks with your metrics
- Update CTAs: Change href and button text
