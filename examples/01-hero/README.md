# Hero Section

Multiple hero layout variations for different use cases.

## Variations

| File | Style | Best For |
|------|-------|----------|
| `output-1-stats-bar.html` | Clean with stats bar | SaaS, agencies, portfolios |
| `output-2-split-image.html` | Split layout with image | Products, apps, startups |
| `output-3-centered-gradient.html` | Centered with gradient orbs | Tech, developer tools |
| `output-4-video-background.html` | Video background | Agencies, creative studios |
| `output-5-minimal-bold.html` | Bold typography, minimal | Design studios, portfolios |

## 1. Stats Bar Hero

Clean hero with headline, description, dual CTAs, and a 4-metric stats bar.

**Features:**
- Responsive headline with `clamp()` sizing
- Primary (filled) and secondary (outline) CTA buttons
- 4-column stats grid with gradient dividers
- Mobile: 2x2 stats grid, centered text

## 2. Split Image Hero

Two-column layout with content on left, image on right.

**Features:**
- Badge/tag for announcements
- Floating notification card with animation
- Avatar stack showing user count
- Play demo button with icon
- Image with subtle border glow

## 3. Centered Gradient Hero

Centered layout with animated gradient orbs in background.

**Features:**
- Dark theme with gradient background
- Animated pulsing orbs (CSS keyframes)
- Announcement pill with "New" badge
- Gradient text effect on heading
- Trust indicators (no credit card, free trial, etc.)

## 4. Video Background Hero

Full-screen video background with overlay.

**Features:**
- Uses `core/video` block for native video player
- Gradient overlay for text readability
- Scroll indicator with bounce animation
- Badge/tagline above heading
- Play showreel CTA

## 5. Minimal Bold Hero

Statement typography with minimal elements.

**Features:**
- Extra large uppercase typography (up to 10rem)
- Accent color on key word
- Animated underline on CTA
- Clean whitespace-heavy design

## Usage

1. Copy the desired `output-*.html` file
2. Paste into WordPress block editor (Code Editor mode)
3. Replace placeholder content and images
4. Switch to Visual Editor

## Customization

- **Colors:** Replace `#c0392b` (primary) and `#0a0a0a` (text)
- **Images:** Update placeholder URLs with your images
- **Video:** Replace video URL in variation 4
- **Stats:** Modify the stat blocks with your metrics
- **CTAs:** Change href and button text
