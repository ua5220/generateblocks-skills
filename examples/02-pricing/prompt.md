# Pricing Table Prompt

## The Prompt

> Create a 3-tier pricing table with monthly prices. Include a "Popular" badge on the middle tier. Each tier has: name, price, description, feature list with checkmarks, and CTA button. The popular tier should be visually highlighted with a different background and larger scale.

## Design Notes

- 3-column grid on desktop, stack on mobile
- Middle tier: Scaled up slightly, dark background, "Popular" badge
- Feature list: Checkmark icons, good spacing
- CTA buttons: Primary on popular tier, outline on others
- Responsive: Single column on mobile
