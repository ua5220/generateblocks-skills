## Features

- 3-column grid layout (stacks on mobile)
- Middle tier scaled up with dark background
- "Most Popular" badge
- Checkmark feature lists using CSS pseudo-elements
- Hover lift effects on cards
- Primary CTA on popular tier, outline on others

## Usage

1. Copy `output.html`
2. Paste into WordPress block editor (Code Editor mode)
3. Update pricing, features, and links
4. Switch to Visual Editor

## Customization

- Change prices: Edit the `$19`, `$49`, `$99` values
- Add/remove features: Duplicate or delete `<li>` blocks
- Adjust colors: Replace `#c0392b` (primary), `#0a0a0a` (dark)
- Change badge text: Edit "Most Popular" span
