# Pricing Table

Multiple pricing table variations for different use cases.

## Variations

| File | Style | Best For |
|------|-------|----------|
| `output-1-three-column.html` | Classic 3-tier with highlighted middle | SaaS, subscriptions |
| `output-2-toggle-billing.html` | With monthly/annual toggle | Flexible billing options |
| `output-3-comparison-style.html` | Side-by-side Free vs Pro | Freemium products |

## 1. Three Column Classic

Classic 3-tier pricing with highlighted middle tier.

**Features:**
- 3-column grid layout (stacks on mobile)
- Middle tier scaled up with dark background
- "Most Popular" badge
- Checkmark feature lists
- Hover lift effects on cards

## 2. Toggle Billing

Three tiers with monthly/annual billing toggle.

**Features:**
- Toggle switch for monthly/annual
- "Save 20%" messaging
- Featured tier with dark background and glow
- Consistent card heights with `margin-top: auto` on CTAs
- Hover border color change

## 3. Comparison Style

Side-by-side Free vs Pro comparison on dark background.

**Features:**
- Two-column layout (dark theme)
- Free tier with "X" marks for unavailable features
- Pro tier highlighted with white background
- "Best Value" badge positioned above card
- Clear visual hierarchy

## Usage

1. Copy the desired `output-*.html` file
2. Paste into WordPress block editor (Code Editor mode)
3. Update pricing, features, and links
4. Switch to Visual Editor

## Customization

- **Prices:** Edit the price values ($9, $19, $29, etc.)
- **Features:** Add/remove list items
- **Colors:** Replace `#c0392b` (primary), `#0a0a0a` (dark)
- **Badge text:** Edit "Most Popular" or "Best Value"
- **Toggle:** For variation 2, implement JavaScript for actual toggle functionality
