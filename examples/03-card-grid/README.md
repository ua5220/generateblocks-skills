# Card Grid

A responsive 3-column card grid for blog posts or portfolio items.

## Features

- 3-column grid (2 on tablet, 1 on mobile)
- Featured image with zoom on hover
- Category badge overlay
- Title color change on hover
- Animated accent border reveal from left
- "Read more" link with arrow animation

## Usage

1. Copy `output.html`
2. Paste into WordPress block editor (Code Editor mode)
3. Replace images, titles, excerpts, and links
4. Switch to Visual Editor

## Customization

- Change category colors: Edit badge `backgroundColor`
- Adjust card spacing: Modify `gap` in grid container
- Different hover effect: Edit the `::after` pseudo-element
- Remove category badges: Delete the category span blocks
