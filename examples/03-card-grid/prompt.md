# Card Grid Prompt

## The Prompt

> Create a 3-column card grid for blog posts or portfolio items. Each card has: featured image, category tag, title, excerpt, and "Read more" link. Cards should have hover effects that lift the card and reveal an accent border. Responsive: 2 columns on tablet, 1 on mobile.

## Design Notes

- 3-column grid with gap
- Image aspect ratio maintained
- Category pill badge overlaid on image
- Title with hover color change
- Subtle shadow on hover
- Animated accent border reveal
