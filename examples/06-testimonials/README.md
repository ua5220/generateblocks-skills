# Testimonials

Multiple testimonial layout variations for social proof sections.

## Variations

| File | Style | Best For |
|------|-------|----------|
| `output-1-default.html` | 3-column grid with avatars | General social proof |
| `output-2-carousel-style.html` | Dark theme with navigation | Featured testimonials |

## 1. Default Grid

3-column testimonial grid with avatars, quotes, and star ratings.

**Features:**
- 3-column grid (2 on tablet, 1 on mobile)
- Decorative quote mark
- 5-star rating with gold stars
- Circular avatar images
- Author name and role/company
- Hover lift effect on cards

## 2. Carousel Style

Dark theme testimonial section with navigation arrows.

**Features:**
- Dark background theme
- Large centered testimonial
- 5-star rating display
- Navigation arrows (prev/next)
- Avatar with name and role
- Clean minimal design

## Usage

1. Copy the desired `output-*.html` file
2. Paste into WordPress block editor (Code Editor mode)
3. Replace testimonial text, names, roles, and avatars
4. Switch to Visual Editor

## Customization

- **Remove stars:** Delete the star rating div
- **Change avatar:** Update the `src` URL (pravatar.cc for placeholders)
- **Different layout:** Modify `grid-template-columns`
- **Add more testimonials:** Duplicate a testimonial block

## Avatar Placeholder

Using `pravatar.cc` for placeholder avatars. Replace with:
- Real images from your media library
- Gravatar URLs
- Custom uploaded images
