# Testimonials Grid Prompt

## The Prompt

> Create a testimonial section with 3 testimonials in a row. Each testimonial card has: quote text, author avatar (circular), author name, and role/company. Add quote marks as decorative element. Cards should have subtle hover effects. Include section heading. Mobile: stack vertically.

## Design Notes

- 3-column grid layout
- Large decorative quote mark
- Circular avatar with border
- Star rating optional
- Cards with subtle shadow on hover
- Testimonial text in italics or regular
