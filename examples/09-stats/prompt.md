# Stats Section Prompt

## The Prompt

> Create a stats/metrics section showing 4 key numbers in a row. Each stat has a large number with optional + or % suffix, and a label below. Use an accent color for the numbers. Add subtle animation or visual interest with borders or backgrounds. Include a brief intro headline above the stats. Mobile: 2x2 grid.

## Design Notes

- 4-column layout on desktop
- Large, bold numbers with accent color
- Uppercase labels in muted color
- Optional: dividers between stats
- Light background for contrast
- Mobile: 2x2 grid arrangement
