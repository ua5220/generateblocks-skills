# Services

Multiple service section layouts for showcasing offerings.

## Variations

| File | Style | Best For |
|------|-------|----------|
| `output-1-default.html` | Bento grid with featured | Service pages |
| `output-2-process-steps.html` | Numbered horizontal steps | How it works |
| `output-3-icon-list.html` | Sticky sidebar + list | Dark theme pages |

## 1. Default Bento Grid

Bento-style grid with featured large card and smaller cards.

**Features:**
- Bento grid layout: 1 large (2-col) + 3 small
- Featured service with dark background
- Icons with hover animation
- Animated accent bar on hover
- "Learn more" links with arrow animation
- Mobile: single column stack

## 2. Process Steps

4-step horizontal process with numbered circles.

**Features:**
- Connected step indicator line
- Numbered circles with hover effect
- Final step highlighted (filled)
- Responsive 2x2 then 1-column
- Clean white background

## 3. Icon List

Sticky sidebar with vertical service list.

**Features:**
- Sticky sidebar with CTA
- Dark theme aesthetic
- Color-coded icons per service
- Slide-right hover effect
- Border accent on hover
- Mobile: stacked layout

## Usage

1. Copy the desired `output-*.html` file
2. Paste into WordPress block editor (Code Editor mode)
3. Update icons, titles, descriptions, and links
4. Switch to Visual Editor

## Customization

- **Equal grid:** Remove `grid-column: span 2` from featured
- **Different icons:** Replace SVG code (Feather Icons style)
- **Remove featured styling:** Make all cards same size/style
- **Add more services:** Duplicate service card blocks
