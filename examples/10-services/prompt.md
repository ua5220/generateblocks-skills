# Services Grid Prompt

## The Prompt

> Create a services section with a bento-style grid layout. One large featured service card (spans 2 columns), and 3 smaller service cards. Each card has an icon, title, description, and a link. The featured card should have a dark background and be more prominent. Add hover effects that reveal a colored accent bar. Mobile: single column.

## Design Notes

- Bento grid: 1 large (2-col) + 3 small (1-col each)
- Featured service: dark background, larger text
- Icons in colored containers
- Animated accent bar on hover
- Links with arrow animation
- Mobile: single column stack
