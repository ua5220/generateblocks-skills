# Comparison Table Prompt

## The Prompt

> Create a feature comparison table comparing 3 products/plans side by side. Include a sticky header row with product names and prices. Show 8+ feature rows with checkmarks, X marks, or text values. Highlight the recommended/popular option. Add a CTA button under each plan. Make the table horizontally scrollable on mobile with a sticky first column.

## Design Notes

- Section padding: 4rem top/bottom
- Background: Light gray
- Table: White background with subtle borders
- Header: Product names, prices, and billing period
- Features: Alternating row backgrounds for readability
- Icons: Checkmark (green), X (red), dash (gray)
- Popular: Highlight column with accent border
- Mobile: Horizontal scroll with first column sticky
