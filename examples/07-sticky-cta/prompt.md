# Sticky CTA Banner Prompt

## The Prompt

> Create a CTA banner that can be used as a sticky footer or inline call-to-action. It should have: headline text on the left, a brief description, and a CTA button on the right. Dark background with high contrast. The layout should be horizontal on desktop and stack on mobile. Add a subtle gradient or accent.

## Design Notes

- Full-width dark background
- Flex layout: text left, button right
- Primary color accent (gradient or border)
- High contrast text for visibility
- Mobile: stack vertically, center-align
- Works as inline section or sticky position
